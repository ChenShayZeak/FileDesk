# 文件桌 · FileDesktop

文件桌是一款支持简体中文和英文的 macOS 文件管理器，用 SwiftUI 和 AppKit 编写。你可以输入路径直接进入目录，按名称或文件夹标签查找项目，在列表和网格中区分隐藏文件，也可以给单个文件创建带密码的加密副本。文件浏览和加解密都在本机完成，无需注册账号。

## 安装与启动

运行环境为 **macOS 14 或更高版本**。从源码构建需要 **Swift 5.9 或更高版本**。如果 Mac 尚未安装开发工具，在终端运行 `xcode-select --install`，等安装完成后再继续。

```bash
git clone https://github.com/ChenShayZeak/FileDesk.git
cd FileDesk
bash scripts/build-app.sh
open dist
```

最后一条命令会在访达中打开构建产物所在的文件夹。把 `FileDesktop.app`（中文显示名为「文件桌」）拖到「应用程序」，按 `⌘空格` 在聚焦中搜索 `FileDesktop` 即可启动。也可以把图标拖到 Dock。首次访问桌面、文稿、下载或外接磁盘时，macOS 可能会询问访问权限。

## 界面语言与外观

文件桌默认跟随 macOS 的语言偏好。要单独切换，在「系统设置 → 通用 → 语言与地区 → 应用程序」中添加 FileDesktop，选择「简体中文」或「English」，然后重新打开文件桌。文件名、标签和路径会保留原文。

使用 Xcode 26 或更新版本的工具链构建后，macOS 26 及以上的侧栏、工具栏和视图切换按钮使用系统液态玻璃效果。较早系统使用标准材质。开启「辅助功能 → 显示 → 降低透明度」后，这些区域使用实色背景。

## 检查更新

打开菜单栏「帮助 → 检查更新…」。文件桌会查询本项目的 GitHub 标签，按版本号选择最新正式版。发现新版时，点「安装更新」会拉取对应标签的源码，在临时目录编译并校验应用，再原位替换已安装的应用。提示安装完成后，退出并重新打开文件桌即可。旧版就地更新会沿用原包名；若聚焦搜不到英文名，可退出文件桌，将「应用程序」中的旧包重命名为 `FileDesktop.app`。

更新需要网络、Git、Swift 开发工具，以及当前应用所在目录的写入权限。更新使用单独的源码副本。仓库尚无正式标签、已经是最新版或更新失败时，应用会显示相应提示。

维护者发布版本时，将要发布的提交打上 `v主版本.次版本.修订号` 标签并推送到 GitHub，例如 `v0.4.0`。也支持 `0.4.0` 形式。预发布标签（如 `v0.4.0-beta.1`）会被跳过。直接检出正式标签并运行打包脚本时，应用会使用标签中的版本号。

## 浏览与管理文件

| 想做什么 | 操作 |
| --- | --- |
| 从访达打开 | 在访达中右键点一个文件夹，选择「用文件桌打开」。如果菜单底部显示「服务」，在其子菜单中选择该项。 |
| 前往指定目录 | 按 `⌘⇧G`，输入路径时会列出匹配的文件夹。例如输入 `~/Dow`，按 Tab 补全为 `~/Downloads/`，再按回车进入。多个候选可用 ↑ / ↓ 选择，也可以继续补全下一级。支持相对路径、带空格的路径和 `..`。 |
| 历史路径 | 点击右上角「显示历史路径」图标展开底部面板，再点一次收起。通过「前往文件夹」访问的目录按最近使用排序。点击路径可重新进入，点右侧的 × 可移除这条记录。 |
| 浏览文件夹 | 从左栏点选常用位置，双击文件夹进入下一级，点击顶部路径返回对应层级。要打开其他目录，可选工具栏「⋯ → 选择文件夹…」或按 `⌘⇧O`。 |
| 最近使用 | 左栏按打开时间显示在文件桌中成功打开的文件，点文件名可再次打开。加密文件解锁后才会记录，再次打开仍需密码。右键可移除一条记录。 |
| 显示或隐藏左栏 | 点击右上角的左侧栏图标可收起或展开。文件桌会记住上次的显示状态。 |
| 我的收藏 | 打开要收藏的目录，点标题旁的星标即可加入左栏「我的收藏」，再点一次可移除。「常用位置」中的个人目录、桌面、文稿、下载和应用程序会隐藏星标，其子目录仍可收藏。 |
| 查找文件 | 按 `⌘F` 输入名称或文件夹标签。搜索包含当前目录及所有可访问的子文件夹。同名结果按所在目录区分，搜索会沿用隐藏文件设置，并跳过软件包内部和符号链接指向的目录。工具栏「⋯」中可以按名称、最近修改、大小或种类排序。 |
| 显示隐藏项目 | 在「⋯ → 显示隐藏文件」中切换。列表和网格都会给点号文件（如 `.env`）以及带 macOS 隐藏属性的项目加上「隐藏」标记。首次使用默认显示，之后沿用上次选择。 |
| 查看或打开文件 | 双击普通文件会用系统默认应用打开。选中项目可在右侧查看大小、位置和修改日期，也可以点「快速预览」。 |
| 快速解压 | 在列表或网格中选中一个压缩包，点击右下角废纸篓旁的「解压」图标，或按 `⌘⇧E`。结果放在压缩包旁的同名文件夹，遇到重名会追加数字，如 `资料 2`。原压缩包会保留。 |
| 复制、移动与重命名 | 右键点项目选择操作。复制后进入目标目录，在「⋯」中点「粘贴文件」。复制或移动遇到同名项目时会提示。 |
| 打开终端 | 点击右上角的终端按钮，在当前浏览的文件夹中打开 macOS 终端。 |
| 复制路径 | 选中项目后点击工具栏的链接图标，或按 `⌥⌘C`。复制成功后，工具栏下方会短暂显示「路径已复制」。多选时每行复制一条绝对路径。右键点击顶部路径栏可以复制当前目录的路径。 |
| 移到废纸篓 | 选中一个或多个项目，按 `⌘⌫` 并确认。误删后可以到系统废纸篓找回。 |
| 给文件夹加标签 | 右键点文件夹，选择「编辑标签…」。保存后，文件桌和访达都能读取这些标签。 |

首次解压时，文件桌会查找已安装的 `7zz`。如果未找到，选择「安装并解压」，文件桌会按当前架构下载官方 7-Zip 26.06、校验 SHA-256，安装到 `~/Library/Application Support/FileDesk/Tools/`，然后继续解压原先选中的文件。首次安装需要联网，无需 Homebrew 或管理员权限。选择「取消」会结束本次操作。支持 ZIP、7z、RAR、TAR、GZip、BZip2、XZ 和 Zstandard，常见的 `.tar.gz` 等组合格式会展开到最终文件。需要密码的压缩包请使用支持输入密码的解压工具。

## 加密、编辑与保存

以 `笔记.txt` 为例：

1. **创建加密副本**。右键点 `笔记.txt`，选择「加密文件…」并设置密码。同一目录生成 `笔记.txt.filedesk` 后，文件桌会询问如何处理明文 `笔记.txt`。默认选择「保留原文件」。选「将原文件移到废纸篓」后，文件桌会核对两个文件的内容，再把明文原件移到系统废纸篓，加密副本留在原位置。
2. **解锁查看**。双击 `笔记.txt.filedesk` 并输入密码。文件桌会打开一个临时解密副本。应用内编辑器支持系统识别为文本类型、大小不超过 2 MiB 的 UTF-8 文件。其他格式可快速预览，或点「用默认应用打开」。
3. **保存修改**。如果使用了外部应用，先在那里保存并关闭文件，再回到文件桌点「保存并关闭」。有修改时，文件桌会重新加密并写回原来的 `.filedesk` 文件，然后清理临时副本。写回失败时会保留临时副本供重试，强制退出也可能留下明文副本。
4. **修改密码**。右键点加密文件，选择「修改密码…」，输入旧密码并确认新密码。此操作会直接更新加密文件。

文件内容使用 AES-256-GCM 分块加密，密钥通过 PBKDF2-HMAC-SHA256 从密码派生。

## 设为默认打开应用

从「应用程序」启动文件桌，点击 **文件桌 → 设为默认文件夹浏览器…**，向 macOS 请求更改普通文件夹的默认应用。在本项目实测的 macOS 27.2 上，系统将普通文件夹类型（`public.folder`）标记为受保护，并拒绝了这项请求。

要直接用文件桌打开当前目录，可在终端运行 `open -b local.filedesk.app .`，也可以在文件桌中按 `⌘⇧G` 输入目录路径。

要恢复访达，在文件桌窗口的工具栏选择「⋯ → 默认打开方式 → 文件夹用访达打开…」。要关联加密文件，在同一菜单选择「.filedesk 文件用文件桌打开…」。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `⌘⇧G` | 输入路径并前往文件夹 |
| `⌘⇧O` | 打开文件夹选择器 |
| `⌘[` / `⌘]` | 后退 / 前进 |
| `⌘F` | 搜索当前目录及子文件夹 |
| `⌘⇧N` | 新建文件夹 |
| `⌘⇧E` | 解压所选压缩包 |
| `⌥⌘C` | 复制所选项目的路径 |
| `⌘⌫` | 将所选项目移到废纸篓，操作前需确认 |

## 开发与测试

在仓库根目录运行 `swift test`。测试覆盖路径跳转、隐藏文件识别、文件夹标签、加密文件修改密码、解密后的修改写回以及冲突处理。

应用源码位于 [Sources/FileDesk](Sources/FileDesk)，测试位于 [Tests/FileDeskTests](Tests/FileDeskTests)。生成 macOS 应用包的脚本是 [scripts/build-app.sh](scripts/build-app.sh)。
